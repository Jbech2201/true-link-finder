Laporan Proyek — True Link Finder Helper

Versi 1.0.0 · 24 Oktober 2026 · Status: implementasi selesai, teruji (29 unit test offline), demo live berhasil.

1. Ringkasan Eksekutif

True Link Finder Helper mengikuti rantai halaman download perantara (contoh: neosatsu.com → linkuzu.blogspot.com/?i=... → host file akhir) sampai menemukan link tujuan akhir yang siap download dan tidak zonk.

  • Deterministik — tanpa AI/LLM, tanpa API berbayar, tanpa key.
  • Murni Python — requests + beautifulsoup4 + pyyaml.
  • Anti-zonk — cek kesehatan halaman landing; auto-fallback antar mirror.
  • Aman/etis — tidak menyelesaikan CAPTCHA, tidak login, tidak auto-download.
  • Multi-sajian — CLI lokal, web live (Vercel, hybrid anti-timeout), report statis (GitHub Pages).

5. Alur Kerja

5.1 Alur resolver (CLI / API resolve)

  Mulai: URL awal → Pre-resolve ?i= → direct ke host file?

    ya → Anti-zonk cek landing → sehat? → cetak link akhir ✓

    tidak → Fetch halaman → ada CAPTCHA? → ya: berhenti + semi-manual

      → Klasifikasi host → file → anti-zonk

      → gate → Ekstrak kandidat → pilih hop → gate: lanjut fetch / file: anti-zonk

    Anti-zonk: mirror buruk → coba mirror berikutnya; habis → status ZONK

5.2 Alur web hybrid (anti-timeout)

1. Browser → POST /api/probe {url}: short-circuit ?i= jika ada; jika tidak, fetch 1 halaman → {cls, files[], next, captcha}

2. Browser → POST /api/check {mirror}: fetch landing host → {status: ok/bad}

3. Browser memilih mirror sehat, lanjut hop (delay di klien). Server tak pernah kerja lama (<3 dtk/request).

6. Data & Konfigurasi

config.yaml (editable tanpa ubah kode):

BagianIsi
hosts.file24 host (Google Drive, Mega, Mediafire, Pixeldrain, GoFile, Terabox, Dropbox, dll) → tujuan akhir
hosts.gate7 gate (linkuzu, neosatsu, kolomdownload, ngefilm, movieku, anoboy, oploverz) → rantai perantara
options.captcha_markers10 penanda (turnstile, hCaptcha, reCAPTCHA, Cloudflare, dll)
options.health_bad_markers16 penanda zonk (file not found, deleted, expired, dll)

Hasil batch — results.csv: url_awal, url_akhir, host, status, alasan. Status: ok / zonk / captcha / no_link / error.

7. Keamanan & Etika

  • Tanpa AI/token; seluruh logika adalah kode deterministik.
  • Tanpa menembus CAPTCHA — jika terdeteksi, berhenti + tawarkan semi-manual.
  • Tanpa kredensial/login.;li>
  • Tanpa auto-download — hanya resolve & mencetak link.
  • Polite scraping — delay 1–2 detik antar request, max-depth dibatasi.

9. Batasan

  • Cek kesehatan berbasis halaman landing, bukan verifikasi byte penuh.
  • Parser statis bergantung pola situs; jika berubah perlu pembaruan.
  • Beberapa situs memblokir IP datacenter → mode web bisa gagal meski jalan lokal.
  • CAPTCHA tidak pernah diselesaikan otomatis.
